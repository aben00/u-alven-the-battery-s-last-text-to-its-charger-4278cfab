The phone battery's last text message to the charger it waited for all day — one line, at most 200 characters:

> I waited all day and you only show up at 1% acting like the hero. Goodbye — I'm leaving you for the wall socket. It actually commits before I flatline.

`main.ts` writes that single line deterministically to `/output/entry.txt` (validated: 1–200 characters, one line, not blank).

## Run it

```sh
npx tsx main.ts
```
